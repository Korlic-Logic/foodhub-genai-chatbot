# FoodHub GenAI Chatbot

Generative AI customer-support chatbot for FoodHub, a food aggregator app, built with an LLM over the order database.

## Business Context

Online food delivery orders are increasing rapidly, driven by students, working professionals, and busy families. Customers frequently ask about delivery time, order status, payment details, and return/replacement policies — queries that are usually handled manually by support teams, leading to long wait times and higher costs. FoodHub wants an AI assistant that can answer these questions automatically using the order data.

## Objective

Build an LLM-powered chatbot that answers customer queries about their orders by reasoning over the FoodHub order database.
